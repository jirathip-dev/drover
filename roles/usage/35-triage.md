## Triage

#1100: the `triage` job files `triage: <fleet> <date>` and spawns a `triage` lane (impl's harness unless `[fleet.<n>.role.triage]` sets one). The lane is read-only on code and changes issues only through `drover triage close <fleet> <n> --why done|duplicate|superseded --evidence <sha|#N|url>`, `drover triage fold <fleet> <n> --spec <file>` (the body becomes `## Spec (current)` over the old text in a `<details>` block) and `drover triage label <fleet> <n> <label>…`; each refuses a protected issue. Its docs pass reads the README, `docs/`, `roles/`, `.drover/rules.md` and any `CLAUDE.md` / `AGENTS.md` and files one `docs:` issue with `drover triage docs <fleet> --findings <file>` (a finding a line; none, no issue; a README with no non-goals section goes first); it never edits docs or the README's intent section. Its `drover done --no-change "<line>" <fleet> <issue>` closes its issue with that line and each change's undo.
