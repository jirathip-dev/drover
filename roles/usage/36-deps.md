## Deps

#1488: `drover deps <fleet>` (orchestrators and the owner only; `tick` runs it every 30 days where `[fleet.<n>] deps = "monthly"`, default off) files `deps: <fleet> <year>-<month>`, queues it on top and spawns a `deps` lane (impl's harness unless `[fleet.<n>.role.deps]` sets one); a fleet with an open `deps:` issue gets no second one. The lane bumps every direct dependency of every ecosystem (Cargo, pnpm or npm, SwiftPM, sha-pinned GitHub Actions, pinned tools) to its latest release in one PR, fixes what breaks, leaves out (and lists with the reason) a bump it cannot make green, and adds or removes no dependency. Its PR body carries a table (dependency, old, new, each lockfile's package count before and after) and goes through the normal gates and review. With `deps = "monthly"`, `tick` also runs the repo's advisory check on the integration head once a day (`cargo deny check advisories`, `pnpm audit` or `npm audit`): a new advisory files `deps: advisory <id>` with the package and fixed version, queues it on top and spawns its lane at once; one issue per advisory id, never twice.
