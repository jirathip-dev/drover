## Events

`drover check` emits `stall`, `lane-dead`, `ready-unmerged`, `ci-missing` (a PR head with no checks `ci_start_minutes` (10) after its push, once per head), `usage-limit` / `signed-out` (a lane's banner or sign-in prompt: new lanes on that host wait), `ask-waiting` (an owner ask open >30 min), a `by: default` decision for each routine ask open `ask_default_minutes` (30), `orphan-lane` (a live agent named like a lane with no spawn event; `spawn` adopts it), `lane-dup` (two live processes of one key; the next drive pass stops all but the newest), `lane-hog` (on a host over its load limit, a lane over half its CPUs 3 drive passes running: drive pauses it once, the owner's ask kills its processes or lets it run), `outbox-stale` (a remote lane's outbox line undelivered for 5 min) and `alerts-off` (page alerts, no webpush notifier) once per state; `drover merge` emits
`evidence-missing` (issue left open) if the evidence comment fails twice. Notifiers get one plain line, or raw event JSON with `format = "json"`. A fleet's own `[[fleet.<name>.notify]]` (same fields)
replaces the global `[[notify]]` for its events; `notify_global = true` in `[fleet.<name>]` sends to both.
Owner-only: `drover pause|resume <fleet>` (PAUSED), `drover drive`, `drover setup|tick`, `drover timer` (the 5-minute job; `timer install` an orchestrator's too), `drover doctor` (host check), `drover reclaim` (idle worktrees' build folders), `drover host destroy <name>` (a cloud host, after a wip save), `drover serve`, the phone page (its writes log `"via":"web"`), and `drover report [id]`, its bug reports.
