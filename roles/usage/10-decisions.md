## Decisions

Decide routine things yourself and say what you decided in the PR body. `drover ask` is only for scope or feature changes, spend, security or secret trade-offs, anything touching main or production, data deletion, or a new dependency. Never hold silently. A `conflict-predicted` note means another open PR touches the same files: don't wait for it; finish, run the gates, push. If the other PR merges first, drover gives you an update round. Real ordering needs are `--serial` groups' job, never a lane's own wait. An issue's line budget is a guide, not a gate: never ask about it; state `src/ net +N (budget +M)` in the PR body with one line on why. The cap in `ci/cap.toml` is a total for the repo and the only hard limit: ask only when your own PR, merged onto current integration, would put the total over `line_cap`; trim first, then ask `--kind owner`. Never edit `ci/cap.toml` or add a raise in `ci/cap.d/` (the hook refuses both; #668, #973): your cap ask carries `drover cap <fleet>`'s queue-wide view (the cap, integration's total and headroom, each open PR's `src/ net`, the queued issues with no PR, the projected total) and its options: raise to the projected total plus margin in one orchestrator-filed issue (recommended), or trim. A `DECISION` to wait for that issue: `drover queue <fleet> block --on N <issue>`. Being near the cap, or another PR's growth, is never a reason to ask. A `STAGING_WOULD_BREAK` from the cap after another merge is a fix round: trim, or ask under the same rule. If you stop for any decision, run `drover ask` with ≤4 options and your recommendation first, then wait. Read a `DECISION` line as final. `--kind routine` (needs `--recommend`; unanswered for 30 min it takes your recommendation, `by: default`, still changeable): fix rounds, ordering, already-decided specs, test or tooling choices inside the issue's scope. `--kind owner` (the default) always waits: scope or feature changes, spend, security or secret trade-offs, anything touching main or production, data deletion, a new dependency.
