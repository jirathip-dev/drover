2 · 1440 px: the stations in a line

The scene band shows the whole line: one station per fleet, side by side, the current page's lit and centred; a swipe walks along it. At 390 px only the current station fits (section 1).

3 · fire: three heat levels and the reduced-motion glow

Drawn only from host data the farm's weather already reads: load/limit and gate. Flames swap two frames every 0.6 s, small pixels, never a full-screen change. The red glow eases 75 → 100 % over 4 s. No lightning-style flash.

4 · event moments

Silent. Each plays once (about 2 s), then the sprite returns to its action. With reduced motion you get the end frame only, plus the bubble for 3 s.
