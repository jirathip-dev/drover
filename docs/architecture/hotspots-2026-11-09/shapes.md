## The cap raise (slice 2)

One file per raise, read at a sha; the highest wins.

```toml
# ci/cap.d/<date>-<cap>.toml   (the filename is for humans and ordering; the value is the field)
line_cap = 45400
why = """free text: the measurement, the open PRs, the projection, the asks it answers"""
```

```toml
# ci/cap.toml, frozen: the fleet name, the floor and the warning margin; never raised again
[fleet.herdsman]
line_cap = 45400
warn_within = 500
```

```rust
/// The effective cap at `sha` (or the working tree when `sha` is `None`): the highest `line_cap` among
/// `ci/cap.toml` and `ci/cap.d/*.toml`, with `warn_within` from `ci/cap.toml` (default 500).
pub struct Cap {
    pub lines: i64,
    pub warn_within: i64,
    /// The file that set it, for `drover cap`'s line and the `cap-near` alert.
    pub from: String,
}
pub fn cap_at_sha(r: &dyn Runner, dir: &Path, sha: Option<&str>) -> Option<Cap>;
```

`.drover/arch.toml` gains, above its tables:

```toml
frozen = ["ci/cap.toml"]
generated = ["assets/types/api.d.ts"]
generate = "just types"

[[collect]]
dir = "ci/cap.d"
glob = "*.toml"
```

The hook (`crates/core/src/hook.rs:96`): `CAP_FILE` becomes `CAP_PATHS: &[&str] = &["ci/cap.toml", "ci/cap.d/"]`;
the refusal text names both; the exemption at `crates/core/src/cli.rs:2150` is unchanged.

## Passive events (slice 4)

```rust
pub struct Event {
    pub seq: u64,
    pub ts: u64,
    pub fleet: String,
    pub issue: Option<u64>,
    pub kind: String,
    /// #973: not activity: `drover check`'s alerts, notes and prompts. Kinds logged before the flag are in
    /// `events::passive::LEGACY`.
    #[serde(default, skip_serializing_if = "std::ops::Not::not")]
    pub passive: bool,
    #[serde(flatten)]
    pub data: Map<String, Value>,
}

impl Event {
    pub fn passive(mut self) -> Event { self.passive = true; self }
    /// The fold's and the idle-pane reader's one question.
    pub fn is_passive(&self) -> bool { self.passive || passive::LEGACY.contains(&self.kind.as_str()) }
}
```

The TS type (`assets/types/api.d.ts`, regenerated by `just types`) gains `passive?: boolean`. The frozen file:

```rust
// crates/core/src/events/passive.rs — frozen in .drover/arch.toml: kinds logged before the flag; only shrinks
pub const LEGACY: &[&str] = &["pending-action", "lane-state", /* … the 71 of today */];
```

## The hotspots report (slice 1)

```rust
pub struct Hot {
    pub file: String,
    pub prs: usize,
    /// #973: distinct PR pairs the file collided in (was: `conflict-predicted` events, one per push).
    pub conflicts: usize,
    pub updates: usize,
}
```

`find`: after `touched` is built, `touched.retain(|f, _| tip.contains(f))` where `tip` is one
`git ls-tree -r --name-only origin/<integration>`; `conflicts(file)` collects `(e.issue, e.data["other"])` into a
set. The report's header and columns are unchanged; `hotspots-<fleet>.json` is the same shape with new meaning
for `conflicts`.
