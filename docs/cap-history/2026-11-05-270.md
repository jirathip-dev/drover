# 24,500 → 24,995 formatted lines: the reset to measured +5%, and a soft `web/` budget (#270)

Decided by the owner (Q5, 2026-11-03): "Re-measure after the migration and set the Rust cap to measured +5% (expect
~11k) with a separate soft budget for `web/` (TypeScript lines reported in each PR, no hard cap), since UI code moves
out of Rust on purpose".

Measured on staging `13428e2` (after #269, the last tab move): 23,804 formatted lines under `crates/*/src`.
23,804 × 1.05 = 24,994.2, so the cap is 24,995.

The ~11k expectation was from before the Rust grew: the board's HTML did leave Rust (the server builds only the page
shell, `just html-lint`), but the CLI, drive, hosts and chat work merged meanwhile kept the total near 24k.

`web/`: `cap-check` now also prints `web lines (TypeScript, soft budget, not capped): <n>` (`web/src/**/*.ts`, 777 at
`13428e2`); it never changes the exit code. Each PR states `web/ net +N` next to `src/ net +N` (the PR template).

The planned step that stays: #345 (Phase C) raises the cap by +3,000 in its own PR.
