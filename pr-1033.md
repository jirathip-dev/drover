board-fix: the lanes tab shows busy lanes as idle (broken status).

## For humans

Lanes that run on shed's agent runtime no longer show as idle while they work. A busy lane now appears under "working" on the lanes tab, with what it is running underneath (for example "running: cargo test (8m)"). The herd view and the native app get the same working state.

## What changed

- `crates/core/src/herdr.rs`: where a shed terminal becomes an agent row, shed's reported `running` becomes `working` (drover's word), and shed's `note` rides along. Fixed at that boundary, so board, herd, drive and check all agree.
- `crates/core/src/lanes.rs`: `Lane.note`; a working lane's `now` line (the lanes row subtitle) is shed's note when present. No API shape change.
- herd `act` for a working impl lane is `impl` (the role's action, as for every working lane); its `state` is `working`.
